# 功能差距总览

“tldraw SDK 状态”表示 SDK 是否提供基础能力；“Drawly 状态”表示当前项目是否已完成产品接入。

| 功能域 | 飞书画板能力 | tldraw SDK 状态 | Drawly 当前状态 | 优先级 | 本阶段是否实现 | 当前是否实现 |
| --- | --- | --- | --- | --- | --- | --- |
| 账号与真实身份 | 登录用户、头像、姓名、组织成员 | 不提供账号系统 | 已实现注册、登录、退出、Session、显示名称及头像颜色 | P0 | 是 | ✅ |
| 画板管理 | 创建、命名、复制、最近使用、删除与恢复 | 不提供业务层 | 已实现我的画板、本人及共享画板最近使用、复制、回收站与恢复 | P0 | 是 | ✅ |
| 分享与权限 | 所有者、可编辑、可查看、链接分享 | 提供只读连接原语 | 已实现登录用户的只读/可编辑链接分享、服务端权限校验和关闭分享 | P0 | 是 | ✅ |
| 协作成员 | 实名光标、成员列表、定位和跟随 | 支持 Presence 和跟随 | 已将登录账号的名称、头像颜色和用户 ID 接入协作用户信息 | P0 | 是 | ✅ |
| 评论与 @ | 锚定评论、回复、@成员、解决评论、定位原文 | 有独立评论包 | 已接入评论图钉、回复、解决、侧栏、真实账号作者与 @ 协作者 | P1 | 是 | ✅ |
| 站内通知 | 被 @、收到回复、评论解决等提醒 | 不提供业务通知系统 | 未实现 | P1 | 否 | — |
| 搜索与替换 | 搜索、逐项定位、替换、全部替换 | 有文本读取 API 和示例 | 未实现 | P1 | 是 | — |
| 模板库 | 浏览、搜索、预览、使用、个人模板 | 不提供模板产品 | 未实现 | P1 | 否 | — |
| 素材库 | 搜索素材、图标、贴纸和最近使用 | 仅提供默认资源加载机制 | 未实现 | P1 | 否 | — |
| 全局配色主题 | 对画板内容快速应用成套配色 | 支持样式扩展 | 未实现 | P2 | 否 | — |
| 导出能力 | 全部/局部导出、PNG 尺寸、透明背景、矢量 PDF、复制图片 | 默认支持 PNG/SVG 等基础导出 | 未形成产品入口 | P1 | 是 | — |
| 外部导入 | 导入 draw.io 内容 | 不提供完整 draw.io 导入器 | 未实现 | P2 | 否 | — |
| 画板翻译 | 翻译画板中的文本内容 | 不提供翻译服务 | 未实现 | P2 | 否 | — |
| 移动端体验 | 平板完整编辑、手机基础编辑 | 支持触控和响应式基础 | 未专项适配和测试 | P2 | 否 | — |
| 数据恢复能力 | 不作为飞书画板直接差距计算；独立本地产品仍需快照和恢复 | 同步层不提供长期版本产品 | 未实现 | P1 | 否 | — |
| 连接状态与容错 | 自动保存提示、离线提示、重连和失败反馈 | 同步层支持重连 | 缺少完整 UI | P1 | 是 | — |
| 内容权限控制 | 控制复制、导出、评论等操作 | 可覆盖 UI，但无业务权限模型 | 未实现 | P1 | 否 | — |
| 审计与安全 | 成员、分享、导出等操作可追踪 | 不提供业务审计 | 未实现 | P0 | 否 | — |
| 管理与运维 | 配额、备份、恢复、监控、清理 | 不提供 | 未实现 | P0 | 否 | — |
